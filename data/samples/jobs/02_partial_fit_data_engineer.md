# Data Engineer (m/f/d)

**Company:** Freightly Logistics SE
**Location:** Hamburg, Germany or remote within Germany
**Seniority:** Mid-level
**Salary:** €62,000 – €72,000
**Language:** English required; German is helpful.
**Visa:** Sorry, we cannot sponsor visas at this time.

## The role
Freightly moves 2 million parcels a month. You will build and run the data pipelines that feed our
delivery-time forecasts and customer dashboards.

## Responsibilities
- Build batch and streaming pipelines with Apache Spark and Kafka.
- Orchestrate workflows in Apache Airflow.
- Model data in our Snowflake warehouse using dbt.
- Run infrastructure on AWS (S3, Glue, Lambda) with Terraform.
- Work with data scientists to put delay-prediction models into production.

## Requirements
**Must have**
- 3+ years of professional experience as a data engineer
- Strong SQL and Python
- Production experience with Apache Spark
- Experience with an orchestrator such as Airflow
- Hands-on AWS experience

**Nice to have**
- Domain knowledge in logistics or transport
- dbt and Snowflake
- Docker and CI/CD
- Experience with machine learning models in production
